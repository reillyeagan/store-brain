# Store Brain

The 24/7 operations brain for Reilly's five Shopify stores: Holt & Crane, Auberlane, Marlowe Standard, Colette & Claire and Tundrelle.

Separate from the Eagano personal brain.

- **Backbone:** Cloudflare (Workers, crons, D1, KV, R2)
- **Thinking:** Claude agents, only where judgement or language is needed
- **Centre:** the Core, a knowledge brain holding everything about every store
- **Screens:** Mission Control, in the Eagano dash aesthetic

Status: Phase 1 (foundation) starting. Nothing in this repo touches a live store yet.
